🎯 Number Guessing Game

Number Guessing Game is a React Native application where users try to guess a randomly generated number within a limited number of attempts. The game provides helpful hints after each guess and handles invalid inputs and game states gracefully, creating a simple and interactive gaming experience.

✨ Key Features

* 🎯 Random number generation
* 🔢 User number guessing
* 🔄 Limited number of attempts
* 💡 Higher/lower hints based on guesses
* 🏆 Win and lose game states
* 🔁 Restart and play again
* ⚠️ Invalid input validation
* 🛡️ Graceful game error handling
* 📊 Attempt tracking
* ⚡ Instant feedback after each guess
* 📱 Interactive React Native UI
* 🎮 Simple and engaging gameplay

🏗️ Architecture & Workflow

The application generates a random target number and allows the user to submit guesses within a predefined attempt limit. Each guess is evaluated against the target number, and the application provides a hint indicating whether the next guess should be higher or lower.

Input validation prevents invalid values from affecting the game, while the application manages winning, losing, and restart states to maintain a smooth gameplay experience.

🛠️ Tech Stack

React Native • JavaScript • React Hooks • State Management • Input Validation • Random Number Generation

▶️ Run the App

1. Install dependencies

npm install

2. Start Metro

npm start

3. Run on Android

npm run android

4. Run on iOS

npm run ios

🎯 Project Purpose

This project demonstrates how to build an interactive game using React Native while managing user input, game state, random number generation, validation, conditional logic, and error handling. It provides practical experience with React Hooks and creating responsive gameplay interactions.
